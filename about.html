关于 / About

关于林骥

应用数学硕士，曾在高校教授《高等数学》；2008 年起从事数据分析工作， 现任企业数据分析部总经理。公众号「林骥」作者，2023 年出版《数据化分析》。

身份 / Roles

教练型的研究者、设计者与联结者

做管理之后我慢慢意识到，命令型的控制者很难带出会思考的团队。我更愿意换一种角色。

01

研究者

从数据里找规律。不只是回答「发生了什么」，还要回答「为什么会这样」，以及「接下来会怎样」。

02

设计者

把方法做成工具。让抽象的思维变成可执行的流程，让人在真实场景里更容易做出判断。

03

联结者

把人和知识连起来。写作、答疑、交流，让一个人的经验变成一群人可以复用的东西。

时间线 / Timeline

从 2008
到现在

没有一条笔直的路径，只有一次次「遇到难题—想办法—复盘」的循环。

  1. 2008

    进入数据分析行业

    一个偶然的实习机会，让我开始从事数据分析工作。那时这还是个新兴职业，国内专业的数据分析师不多，只能靠自己摸索。

  2. 2012

    网名「数据化分析」

    开始在微博和博客上分享学习心得与工作经验：对客观真实的数据，运用恰当的方法和工具，进行科学有效的分析。

  3. 2016

    开设微信公众号

    公众号命名为「林骥」——不想被「数据化分析」这个标签限制写作范围，只要对读者有价值，都可以写。

  4. 2018

    「数据赋能系统」雏形

    基于 Excel 开发，运用数据分析思维形成「感知数据—认知规律—帮助决策—付诸行动」的正向循环，用来驾驭自己的时间、情绪和习惯。

  5. 2019

    写作成为日常

    重新开始并坚持每天写作、每天复盘。写作既是梳理自己，也是训练结构化思维与逻辑表达。

  6. 2020

    整理电子书

    把已发表的文章修订成册，形成《数据化分析 Python 实战》，作为阶段性沉淀。

  7. 2023

    出版《数据化分析》

    由电子工业出版社出版，全彩 244 页。删去了大量代码，只保留十年后仍有参考价值的思维、工具、方法与模型。

  8. 至今

    每天复盘总结

    把每一次遇到的困难、挑战和痛苦，都当成提升自己的机会。

未来 / Ahead

为什么是
「大师」

未来的路还有很长。我希望成为一个数据化分析大师——能从数据中得出商业洞察， 优化改进业务运营流程。

为什么是「大师」而不是「专家」？因为专家主要指在某个方面有专业技能， 有时会钻进死胡同，成为「砖家」。而要想成为大师，不仅要专业造诣深厚， 还要有知识创新，并且对社会贡献的价值更大。

这大概也是我做这个网站的初衷：把散落在各处的思考收拢到一处， 让它们可以被检索、被引用、被继续写下去。
